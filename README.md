# Aprendizaje Automático

Este repositorio se utiliza como espacio de apoyo para las clases correspondientes al **bloque de Aprendizaje Automático**.

Su objetivo principal es compartir material práctico que permita complementar los contenidos desarrollados durante las clases.

## Contenido del repositorio

Aquí se podrán encontrar:

- Ejemplos desarrollados durante las clases.
- Ejercicios prácticos.
- Actividades para resolver.
- Jupyter Notebooks.
- Ejemplos de código en Python.
- Datasets utilizados en las prácticas.
- Ejercicios de manipulación, limpieza y preparación de datos.
- Ejemplos de visualización y análisis exploratorio de datos.
- Implementaciones básicas de algoritmos de Aprendizaje Automático.

## Jupyter Notebooks

Gran parte del material se encuentra desarrollado mediante **Jupyter Notebook (`.ipynb`)**, ya que este formato permite combinar:

- Código Python.
- Explicaciones teóricas.
- Ejemplos.
- Resultados de ejecución.
- Tablas.
- Gráficos.
- Ejercicios.

Los notebooks pueden ejecutarse utilizando diferentes entornos, por ejemplo:

- Jupyter Notebook.
- JupyterLab.
- Visual Studio Code.
- Google Colab.

## Uso del material

El material de este repositorio tiene fines principalmente **educativos** y está pensado para acompañar el desarrollo de las clases.

Se recomienda utilizar los ejemplos como punto de partida, ejecutar el código, modificar parámetros y experimentar con los distintos ejercicios para comprender mejor el comportamiento de las herramientas y algoritmos utilizados.

## Temas

A lo largo del bloque se podrán incorporar materiales relacionados con temas como:

- Introducción al Aprendizaje Automático.
- Preparación de datos.
- Manipulación de datos con Pandas.
- Limpieza de datos.
- Análisis exploratorio de datos.
- Visualización de datos.
- Datos sintéticos.
- Preprocesamiento.
- Escalado y normalización.
- Selección de variables.
- Aprendizaje supervisado.
- Aprendizaje no supervisado.
- Regresión.
- Clasificación.
- Clustering.
- Evaluación de modelos.
- Validación cruzada.
- Ajuste de hiperparámetros.

## Importante

Los datasets utilizados en los ejemplos pueden ser:

- Datos públicos.
- Datos adaptados con fines educativos.
- Datos simulados o sintéticos.

Cuando se utilicen datos sintéticos, estos serán generados exclusivamente para realizar ejercicios y **no representan personas, empresas o situaciones reales**.
